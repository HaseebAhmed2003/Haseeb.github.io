  • Category: Machine Learning

Problem and contribution

A personal vehicle-image classification interface. I connected image upload and preprocessing to a saved Keras model and displayed the predicted vehicle class.

Implementation

The local Streamlit app resizes images to 300 × 300, applies EfficientNet preprocessing, adds a batch dimension, runs model.predict, and maps argmax to seven vehicle classes.

Evidence and limits

The inference code was inspected locally. The training run, reported validation accuracy, saved model behavior, and hosted demo have not been revalidated. The app currently reloads the model for each image; caching and explicit RGB conversion are useful next steps.

Historical hosted demo: use the project link above. Availability is not guaranteed.
